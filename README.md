# English Teacher Bot

Telegram-бот + мини-приложение для преподавателя английского: запись на уроки, админ-панель, оплаты, журнал действий, статистика загрузки.

## Возможности

**Ученик (в боте и мини-приложении)**
- Регистрация: имя, уровень (A1–C2), цель
- Запись на свободные слоты, перенос, отмена (с правилом поздней отмены)
- Мои уроки, баланс оплаченных уроков, домашние задания
- Напоминания за 24 часа и за 1 час

**Преподаватель**
- Заявки: подтвердить / отклонить в один клик (или автоподтверждение)
- Сегодня / неделя, отметки «проведён», «неявка», тема и ДЗ (отправляется ученику)
- Карточки учеников: заметки, оплаты, история, блокировка, личное сообщение
- Рассылка всем ученикам, экспорт в CSV (уроки, ученики, оплаты, журнал)
- Мини-приложение: календарь-тепловая карта загрузки, расписание дня, выходные и блокировка времени, статистика, журнал, настройки
- Журнал (`logs`) пишет каждое действие: кто, что, когда

## Запуск

```bash
npm install
cp .env.example .env   # заполнить BOT_TOKEN и ADMIN_IDS
npm start
```

1. `BOT_TOKEN` — у @BotFather: `/newbot`.
2. `ADMIN_IDS` — запустите бота, напишите ему `/id`, вставьте число в `.env`, перезапустите.
3. `WEBAPP_URL` — HTTPS-адрес мини-приложения. Для теста на своём компьютере:
   `cloudflared tunnel --url http://localhost:8080` → вставьте выданный `https://….trycloudflare.com`.
   Для постоянной работы — сервер/VPS или Railway/Render с доменом.

## Демо без Telegram

```bash
npm run demo
```
Открывает панель на http://localhost:8080 с тестовыми данными (отдельная база `data/demo.db`).
`?as=1001` — посмотреть глазами ученика.

## Структура
- `src/db.js` — SQLite-схема, расписание, брони, оплаты, статистика, журнал
- `src/bot.js` — логика бота (grammY)
- `src/web.js` — API мини-приложения с проверкой подписи Telegram initData
- `webapp/` — мини-приложение (HTML/CSS/JS)
